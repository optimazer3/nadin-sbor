# Бот задач для руководителя

Telegram-бот, в который руководитель записывает задачи для команды голосом или текстом.

- 🎙 **Голосовые задачи.** Руководитель записывает голосовое, бот распознаёт речь (AssemblyAI),
  разбирает текст на задачу, исполнителя и срок (Claude API) и спрашивает: «Я правильно понял?».
  Нажали **«✅ Да, сохранить»** — задача записана в базу (Supabase). Нажали **«❌ Нет»** — можно
  надиктовать ещё раз или прислать исправленный текст. В одном голосовом можно продиктовать
  несколько задач.
- ✍️ Текстом работает так же, как голосом.
- 📋 **Список задач.** Фильтры «Активные / Архив / Все», карточка задачи. В карточке можно сменить
  статус, исправить текст, исполнителя или срок (тоже голосом), удалить задачу.
- 📊 **Дашборд.** Сводка всех активных задач: сколько в каком статусе, сколько просрочено,
  задачи по исполнителям. Приходит **каждый понедельник в 10:00 по Москве**, а ещё его можно
  открыть кнопкой в любой момент.

Статусы: 🆕 Новая → 🔄 В работе → ⏸ На паузе → ✅ Выполнена / ❌ Отменена.
Активными считаются «Новая», «В работе» и «На паузе».

Ботом пользуется только руководитель (или несколько человек из `ADMIN_IDS`). Остальным бот отвечает,
что доступа нет.

## Что понадобится

| Что | Где взять |
|---|---|
| Python 3.11+ | [python.org](https://www.python.org/downloads/) |
| Токен Telegram-бота | [@BotFather](https://t.me/BotFather) → `/newbot` |
| Проект Supabase | [supabase.com](https://supabase.com) → New project |
| Ключ AssemblyAI | [assemblyai.com](https://www.assemblyai.com) → Dashboard → API Keys |
| Ключ Claude API | [platform.claude.com](https://platform.claude.com) → API Keys |

## Установка и запуск (локально)

**1. База данных.** В Supabase откройте **SQL Editor → New query**, вставьте содержимое
[`supabase/schema.sql`](supabase/schema.sql) и нажмите **Run**. Появится таблица `tasks`.
Затем в **Project Settings → API** скопируйте **Project URL** и ключ **service_role**.

**2. Зависимости.**

```bash
python -m venv .venv
```

macOS / Linux:

```bash
source .venv/bin/activate
```

Windows (PowerShell):

```bash
.venv\Scripts\Activate.ps1
```

```bash
pip install -r requirements.txt
```

**3. Настройки.** Скопируйте пример и заполните ключи:

```bash
cp .env.example .env
```

| Переменная | Что это |
|---|---|
| `BOT_TOKEN` | токен от @BotFather |
| `ADMIN_IDS` | Telegram ID руководителя (несколько — через запятую) |
| `SUPABASE_URL`, `SUPABASE_KEY` | Project URL и ключ service_role |
| `ASSEMBLYAI_API_KEY` | ключ AssemblyAI |
| `ANTHROPIC_API_KEY` | ключ Claude API |
| `TEAM_MEMBERS` | имена сотрудников через запятую: бот поймёт «Ване» → «Иван» и покажет кнопки выбора исполнителя |
| `TIMEZONE`, `REMINDER_DAY`, `REMINDER_TIME` | когда слать дашборд (по умолчанию `Europe/Moscow`, `mon`, `10:00`) |

Свой Telegram ID можно не искать заранее: запустите бота, напишите ему `/start`, и он пришлёт
ваш ID. Впишите его в `ADMIN_IDS` и перезапустите бота.

**4. Запуск.**

```bash
python -m bot
```

В логе появится строка вида `Еженедельный дашборд: следующая отправка 2026-11-09 10:00:00+03:00`.
Остановить бота: `Ctrl+C`.

> ⚠️ Пока бот запущен локально, напоминание придёт, только если в понедельник в 10:00 компьютер
> включён и бот работает. Если компьютер проснётся позже (в течение 6 часов), дашборд отправится
> сразу после пробуждения. Чтобы напоминания приходили всегда, бота нужно перенести на сервер.

## Как пользоваться

- **Новая задача:** запишите голосовое, например *«Ване подготовить отчёт по продажам до пятницы,
  а Маше обновить прайс к среде»*. Бот покажет, что распознал и как понял задачи. Нажмите
  «Да, сохранить».
- **Список задач:** кнопка «📋 Список задач» или `/tasks`. Нажмите на задачу, чтобы её открыть.
  В карточке быстрые кнопки «🔄 В работе» и «✅ Выполнена», полный список статусов,
  а также «✏️ Текст», «👤 Исполнитель», «📅 Срок» и «🗑 Удалить».
- **Срок** можно выбрать кнопкой (сегодня, завтра, пятница, через неделю) или написать / сказать:
  `15.11`, `завтра`, `в пятницу`, `к концу месяца`. `-` убирает срок.
- **Дашборд:** кнопка «📊 Дашборд» или `/dashboard`.
- `/cancel` отменяет текущее действие.

## Как это устроено

```
bot/
  main.py               запуск: Telegram, Supabase, планировщик
  config.py             настройки из .env
  handlers/
    common.py           /start, меню, дашборд
    create.py           голос/текст → «Я правильно понял?» → сохранение
    tasks.py            список, карточка, статусы, редактирование
  services/
    transcriber.py      AssemblyAI: загрузка аудио и распознавание
    task_parser.py      Claude: текст → задачи (структурированный JSON)
  repository.py         работа с таблицей tasks в Supabase
  scheduler.py          дашборд и еженедельное напоминание (APScheduler)
  views.py, keyboards.py  тексты сообщений и кнопки
  dates.py              разбор и форматирование дат
supabase/schema.sql     схема базы
tests/                  тесты
```

- Распознавание: аудио загружается в AssemblyAI (`/v2/upload`), язык `ru`. Модель можно задать
  в `ASSEMBLYAI_SPEECH_MODEL`; если оставить пустым, AssemblyAI выберет модель по умолчанию.
- Разбор задачи: модель `claude-opus-5-5` (меняется в `ANTHROPIC_MODEL`) возвращает JSON по строгой
  схеме: формулировка, исполнитель, срок. Модели передаётся календарь на три недели вперёд, чтобы
  «до пятницы» превращалось в точную дату. Включён серверный fallback: если модель откажется
  обрабатывать запрос, API сам повторит его на резервной модели.
- Если Claude недоступен, бот всё равно предложит сохранить задачу: текст целиком станет
  формулировкой, а исполнителя и срок можно будет поставить в карточке.
- Черновики (ещё не подтверждённые задачи) хранятся в памяти бота и теряются при перезапуске.
  Сохранённые задачи хранятся в Supabase.

## Тесты

```bash
pip install -r requirements-dev.txt
```

```bash
pytest
```

Тесты не ходят во внешние сервисы. Telegram, AssemblyAI, Claude и база подменены заглушками,
а сценарии (голосовое → подтверждение → сохранение → список → смена статуса → редактирование →
дашборд) прогоняются через настоящий диспетчер aiogram.
